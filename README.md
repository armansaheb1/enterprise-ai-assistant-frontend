# AI Assistant Platform Frontend

Frontend platform for AI assistants, image generation, face swap, chat, and AI-powered productivity tools.

## Overview

AI Assistant Platform is a web application that provides users with access to conversational AI, image generation, face swap tools, and AI-powered productivity services.

The platform communicates with a Django REST backend and offers a unified workspace for AI-driven workflows.

## Features

- AI chat interface
- GPT-powered conversations
- Image generation tools
- Face swap functionality
- Logo generation
- User dashboard
- Transaction management
- Subscription and package management
- User authentication
- Phone verification
- Support system
- Responsive interface

## Tech Stack

### Frontend

- Vue.js
- Vue Router
- Vuex
- Axios
